Live DO state-survival and disposable artifact revision verification also pass. Conflicts and rejected stale fences are expected outcomes in the contention workloads.

Latency remains advisory. The first journal replay run measured p95 of 436 ms versus the earlier 327 ms baseline; its repeat returned to 356 ms (9% above baseline). Writer acquire p95 similarly fell from 476 ms to 402 ms (10% above the earlier 366.67 ms). The cadence runs missed 6/360 and 1/360 deadlines, respectively, matching the range already observed in today's earlier controls. These short runs do not establish a 500 ms tail guarantee. All five restarts returned acknowledged success, and cold-first-read p50 was 262 ms. The earlier baseline's deliberately aborted restart responses used a different contract and are not equivalent verified restart samples.

Runs use one full-scope D1 credential on a disposable project, the existing deployed Worker, and one macOS arm64 client. Responses report `WAW/local-WAW`; this does not independently establish DO location. Source revisions and dirty-worktree status in the generated tables are retained as measured.
